# Customer Churn Prediction

## Project Overview
This project uses machine learning to predict customers who are likely to leave a service.

## Dataset
IBM Telco Customer Churn Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Joblib

## Machine Learning Models
- Logistic Regression
- Balanced Logistic Regression
- Random Forest
- Improved Balanced Logistic Regression with feature engineering

## Data Processing
- Missing value handling
- Categorical variable encoding
- Feature engineering
- Outlier analysis
- Train-test splitting
- Class imbalance handling

## Features Created
- Tenure Group
- Average Monthly Spend

## Evaluation
The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Application
A Streamlit application was created to provide customer churn risk predictions.

## Project Files
- `Customer_Churn_Prediction.ipynb` - Complete notebook with code and results
- `app.py` - Streamlit application
- `customer_churn_improved_model.pkl` - Trained machine learning model
- `requirements.txt` - Required Python libraries
